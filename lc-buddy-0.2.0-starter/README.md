# LC Buddy shared repo

1. Fill in both `leetcodeUsername` values in `members.json`.
2. Commit this folder to a shared Git repository.
3. Both people install `lc-buddy-0.2.0.vsix`, open this repo in VS Code, then run `LC Buddy: Initialize Workspace`.
4. Let LC Buddy configure the normal LeetCode extension to save C++ files under your own `solutions/<name>/` directory.
5. Use `LC Buddy: Sync Code & Status with Git` after solving.
